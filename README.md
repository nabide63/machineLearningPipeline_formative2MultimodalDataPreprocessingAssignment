## System Overview

This system authenticates a user through **facial recognition** and **voiceprint verification** before serving **personalised product recommendations**. All three checks run sequentially — any failure stops access.

```
Customer ID entered
       │
       ▼
┌──────────────┐    fail     ┌──────────────────┐
│ Face         │ ──────────► │  ACCESS DENIED   │
│ Recognition  │             └──────────────────┘
└──────┬───────┘
       │ pass
       ▼
┌──────────────┐    fail     ┌──────────────────┐
│ Voiceprint   │ ──────────► │  ACCESS DENIED   │
│ Verification │             └──────────────────┘
└──────┬───────┘
       │ pass
       ▼
┌──────────────────────────┐
│  Product Recommendation  │
│  (top-3 categories shown)│
└──────────────────────────┘
```

## Quick Start

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Train the models
```bash
# Face recognition model  (reads image_features.csv)
python scripts/train_face_model.py

# Voiceprint model  (reads data/audio/ → builds audio_features.csv → trains model)
python scripts/train_voice_model.py
```
> The product model (`models/product_recommender.joblib`) is already trained and committed.

### 3. Run the CLI app
```bash
python main.py
```

## System Demonstration Scenarios

### Authorised full transaction
```
python main.py → option 1
Customer ID: 125
Face image : Images/Laura/neutral.jpeg
Voice file : data/audio/Laura 1.mp4
→ Identity verified → product recommendation displayed
```

### Unauthorised face attempt
```
python main.py → option 2
Face image : (any image of a non-team-member)
→ 🚫 ACCESS DENIED – Face not recognised
```

### Unauthorised voice attempt
```
python main.py → option 3
Voice file : (audio from someone not in the team)
→ 🚫 ACCESS DENIED – Voice not verified
```
